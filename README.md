# 酌间

一个手机优先的酒食推荐网页原型。

## 直接体验

双击 `index.html` 即可打开。建议使用 Chrome、Safari 或 Edge。

## 当前包含

- “先选酒 / 先选食物”双入口
- 口味预设、独立味觉滑杆和心情能量滑杆
- 五步单页向导：每次只出现当前一组选项，可随时返回修改
- 类别、场景与搭配筛选
- 酒与食物的双向推荐
- 调酒 / 烹饪材料与步骤
- 连续三次换推荐后进入 DIY 模式
- 本地收藏与随机灵感
- 桌面端与手机端自适应布局

所有照片已经放在 `assets` 文件夹中；收藏数据只保存在当前浏览器。

当前照片来自 Unsplash，仅用于产品原型；正式上线前请确认图片授权或替换为自有素材。
